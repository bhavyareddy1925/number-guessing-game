
🎯 Number Guessing Game

A simple Number Guessing Game built using Python.
The player selects a difficulty level and tries to guess the randomly generated number within a limited number of attempts.

🚀 Features

- 🎮 Easy, Medium, and Hard levels
- 🔢 Random number generation
- 💡 High/Low hints
- ❤️ Attempt tracking
- 🔄 Play again option
- ❌ Input validation

🛠️ Technologies

- Python 3
- "random" module

▶️ How to Run

 number_guessing_game.py

📚 Concepts Used

- Variables
- Functions
- Loops
- Conditional statements
- User input
- Random number generation
- Exception handling
